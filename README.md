# ATM System Simulation 🏦

A high-fidelity Java console application that simulates a real-world Automated Teller Machine. This project focuses on **Object-Oriented Design**, **File Handling**, and **Robust Input Validation**.

## 🌟 Key Features
* **Persistent Storage:** Account data and transaction history are saved to `.txt` files, ensuring data is kept between sessions.
* **Security Logic:** Encrypted-style PIN validation and unique account number generation.
* **Transaction Logging:** Generates a `statement.txt` for every deposit and withdrawal with timestamps.
* **Input Sanitization:** Uses Regex and custom handlers to prevent crashes from invalid user inputs (letters, negative numbers, etc.).

## 🛠️ Technical Stack
* **Language:** Java (JDK 11+)
* **Concepts:** Encapsulation, File I/O (BufferedReader/Writer), ArrayLists, Regex validation.

## 🚀 How to Run
1. Clone the repo: `git clone https://github.com/anupsharma04/ATM-System-Simulation.git`
2. Compile: `javac Main.java`
3. Run: `java Main`
